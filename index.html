Calculer des pourcentages

Facultatif : créez un ratio entre deux indicateurs. Exemple : Tirs favorables ÷ Tirs tentés = pourcentage de tirs favorables.


Maximum : 6 indicateurs, 20 cases par ligne. Les intitulés saisis ici seront repris tels quels dans les résultats et le PDF. La configuration est conservée sur cet appareil.

Lire mes fiches

Sur téléphone : choisissez une photo existante dans votre photothèque ou vos fichiers, ou utilisez l’appareil photo si votre navigateur le propose.

Sélectionnez plusieurs photos ou utilisez l'appareil photo. Les quatre carrés noirs doivent être visibles.

Confidentialité : cette version n'envoie pas les photos vers un serveur : l'analyse est effectuée localement dans le navigateur. Pour une utilisation avec des productions d'élèves, évitez néanmoins les visages et informations personnelles sur les photos.
